Ollama 本地描述增强（可选）

配置本机 Ollama 后，页面加载时会为缺少或过短的条目生成一行产品描述，并缓存在浏览器。 拓展分析（同类 / 上下游 / 亮点）仅在展开某条目时按需调用 Ollama，结果同样缓存在浏览器。 从 GitHub Pages（github.io）访问时，浏览器可能因 CORS 无法直连 localhost；请在本仓库根目录用静态服务器打开、使用同源反代，或设置 OLLAMA_ORIGINS 允许站点来源。未配置或连接失败时仍显示 API 原始描述。
